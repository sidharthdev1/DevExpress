## ✨ Features

- 📱 **Modern UI/UX**: Designed using Material Design components for an intuitive user experience.
- ⚡ **Optimized Performance**: Efficient memory management, asynchronous processing, and smooth navigation.
- 🏗️ **Scalable Architecture**: Built following MVVM (Model-View-ViewModel) patterns to ensure clean separation of concerns.
- 🛡️ **Secure Configuration**: Configured with strict `.gitignore` protection to ensure API keys and SDK paths remain private.

- [Android Studio](https://developer.android.com/studio)
- JDK 17 or higher
